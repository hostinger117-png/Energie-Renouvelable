# ☀️  ENERGIE - Landing Page Practice

> Simple landing page for practice - HTML, CSS & AI Chatbot with n8n

This is a practice project. The goal was to build a clean landing page about renewable energy and integrate a mini AI chatbot.

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (No framework)
- **AI Chatbot:** n8n Workflow + OpenAI API
- **Icons:** Font Awesome / Google Fonts

### ✨ Features
- Responsive design (Mobile friendly)
- Sections: Hero, Services, Stats (15000+ clients), Contact
- Clean UI for a solar energy company (AirSolar / Airwell)
- Floating AI Chatbot that answers questions about:
    - Solar panels & 30-year warranty
    - Heat pumps
    - Energy savings

### 🤖 n8n Chatbot Workflow
1.  `Chat Trigger` in n8n
2.  `ChatBot Agent` 
3.  `Webhook` connected to the frontend chat bubble
